# estudios

**Mi plan de estudios** es una página web de un solo archivo con tres pestañas:

- **Ruta de Software**: las mallas de Cibertec, IDAT y Tecsup en una sola ruta autodidacta con Python, con recursos online, certificaciones, plataformas y libros.
- **Maestría UTP**: Gerencia de TI y Transformación Digital, curso por curso, con conceptos clave y preguntas de repaso.
- **Publicidad UCSM**: los 10 ciclos de la carrera para repasar.

## Cómo usarla

Abre `Mi plan de estudios.html` en el navegador. No necesita instalar nada.

- Marca cada tema o curso al terminarlo. El avance se guarda en el navegador.
- **Sigue con** te lleva al siguiente tema sin marcar.
- Usa el buscador y los filtros (sin marcar, por estudiar, los domino…) para encontrar temas rápido.
- Cada etapa, bloque o ciclo muestra cuántos llevas (por ejemplo `3/6`).
- **Respaldo de tu avance**: descarga un archivo `.json` con lo marcado y restáuralo en otro navegador o dispositivo.
